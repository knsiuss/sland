# 11 Compatibility Requirements

- CR-001 (v1): Windows 10 build 17763+ dan Windows 11 (x64).
- CR-002 (v1): Tajam dan benar posisi di skala 100 / 125 / 150 / 200%+.
- CR-003 (v1): 2 monitor beda DPI + cabut-colok monitor tanpa restart.
- CR-004 (v1): RDP / VM / GPU lemah → fallback solid (tanpa material eksperimental).
- CR-005 (v1): Taskbar atas / bawah / auto-hide tidak menutupi island.
- CR-006 (v1): Node 20+ untuk tooling; versi Electron di-pin di `package.json`.
- CR-007 (v1): Berjalan tanpa hak admin.

Matriks uji manual: `../window-overlay.md` (bagian matriks uji).
