# 04 UI Requirements

- UI-001 (v1): Ukuran fixed DIP — collapsed 430×72, expanded 590×320.
- UI-002 (v1): Apple-clean: pill hitam pekat, teks putih, font sistem (Segoe UI di Windows).
  Tanpa gradien ungu, tanpa emoji di UI.
- UI-003 (v1): Radius dari CSS (`border-radius` pill), bukan mengandalkan DWM.
- UI-004 (v1): Handle drag sempit di tepi pill; semua kontrol `no-drag` dan bisa diklik.
- UI-005 (v1): Kontras teks ≥ 4.5:1 di atas pill; ukuran sentuh kontrol ≥28px.
- UI-006 (v1): Artwork kosong → placeholder netral (bukan gambar rusak).
- UI-007 (v1): Fokus keyboard terlihat (outline) saat navigasi Tab.
